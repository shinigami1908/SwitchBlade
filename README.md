# SwitchBlade

A personal backlog for the things you mean to get to — films, TV, and games — with a home screen that gives you something to read while you decide.

Built with SwiftUI and SwiftData for iOS 18+.

<img src="SwitchBlade/Assets.xcassets/AppIcon.appiconset/AppIcon.png" width="120" alt="SwitchBlade icon">

## What it does

**Shelves.** Three of them — Movies, TV Shows, Games — plus any custom shelf you add. There are no statuses to maintain: anything on a shelf is in the backlog. When you finish something you mark it watched or played and it leaves the app. The shelf is the backlog, so a finished entry has nowhere left to sit.

Add a title and the details fill themselves in: description, year, genres, cast or studio, cover art, and ratings. Rename an entry and it re-fetches from scratch, because a changed title means it now refers to a different work.

**Home.** Time, date, and local conditions, then two words of the day taken straight from Merriam-Webster's and Wordsmith's own feeds, then twenty Wikipedia articles worth reading. Tap "New set" for twenty more. Anything you save with the heart is kept but gives up its slot in the feed, so saved reading never crowds out new reading.

**Search and filter.** Fuzzy title matching that tolerates misspellings and dropped articles, plus filtering by genre and vibe.

## Building

Requires **Xcode 26** or later and [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```bash
brew install xcodegen
```

The `.xcodeproj` is generated from [`project.yml`](project.yml) rather than committed, so the two can't drift apart:

```bash
xcodegen generate && open SwitchBlade.xcodeproj
```

Run that again after adding or removing a source file.

### Signing

To run on a real device, put your Team ID in an untracked config file so it survives regenerating the project and never reaches the repository:

```bash
cp Local.xcconfig.example Local.xcconfig   # then edit in your team
xcodegen generate
```

Find your Team ID — the `OU` field — with:

```bash
security find-certificate -c "Apple Development" -p | openssl x509 -noout -subject
```

A free Apple ID is enough. Apps signed with one stop launching after seven days and need reinstalling; a paid Developer Program membership extends that to a year. The simulator needs no signing at all.

## API keys

The app needs a couple of free API keys to fill in metadata. **Add them in Settings → API Keys inside the app** — each key is written to the iOS keychain and never to preferences, never to a file in this repo, and never off the device except to the service it belongs to.

| Provider | Needed? | What it gives you | Sign up |
|---|---|---|---|
| **TMDB** | Required | Descriptions, genres, posters, and years for films and TV | [themoviedb.org](https://www.themoviedb.org/settings/api) |
| **Google Gemini** | Required | Vibe tags and custom-shelf entries; free tier, no card | [aistudio.google.com](https://aistudio.google.com/apikey) |
| **OMDb** | Optional | Exact IMDb ratings — TMDB scores are used without it | [omdbapi.com](https://www.omdbapi.com/apikey.aspx) |
| **IGDB** | Optional | Cover art for console games, including PS5 exclusives | [api-docs.igdb.com](https://api-docs.igdb.com/#account-creation) |

IGDB needs a Client ID *and* Secret, both from Twitch. Its access token lasts about 60 days and the app refreshes it automatically, so the two credentials you enter don't expire.

Four more sources need no key at all: Wikipedia, Steam, Open-Meteo for weather, and the two dictionary RSS feeds.

### Keeping the Gemini bill at zero

Model calls are capped by a daily budget you can see and change in Settings, well under Gemini's free-tier quota. Films and TV come from TMDB and games from Steam or IGDB — none of which touch the budget. The model is used only for vibe tags, batched twenty titles per call, and for custom shelves.

## App icon

Four styles, switchable in Settings → App Icon: **Adaptive** (follows the system, including the tinted home screen), **Light**, **Dark**, and **Neon**.

The mark is a folding knife opened far enough that the handle and blade form a checkmark — the name, and the app's one real action.

Artwork is generated by code rather than stored as a flat export, so the palette can follow `Design/Theme.swift`:

```bash
swift Tools/MakeAppIcon.swift SwitchBlade/Assets.xcassets
```

That writes every icon set, every settings preview, and their `Contents.json` files. Adding a fifth style means one entry in `iconSets` in [`Tools/MakeAppIcon.swift`](Tools/MakeAppIcon.swift), one case in `AppIconStyle`, and one name appended to `ASSETCATALOG_COMPILER_ALTERNATE_APPICON_NAMES` in `project.yml`.

## Layout

```
SwitchBlade/
  App.swift            Entry point, first-launch seeding
  Design/Theme.swift   Palette, metrics, shared surfaces
  Models/Models.swift  SwiftData models
  Services/            Metadata providers, feeds, keychain, settings
  Views/               Screens and shared components
Tools/MakeAppIcon.swift  Icon generator
project.yml              XcodeGen project definition
```

A few pieces of `Services/` are worth knowing about:

- **`TitleMatcher`** scores candidate titles symmetrically, so a one-word query can't match a much longer title that merely contains it, and a sequel is never returned for the original.
- **`MathCleaner`** repairs Wikipedia's plaintext extracts, which flatten `<math>` markup into a column of stray characters followed by raw LaTeX.
- **`EnrichmentService`** routes each shelf kind to the right provider and marks hand-edited entries so a later refresh won't overwrite them.
- **`KeychainStore`** surfaces the real `OSStatus` on failure instead of silently dropping writes.
